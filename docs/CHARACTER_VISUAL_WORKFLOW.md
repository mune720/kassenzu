# 主要キャラクター・ビジュアル制作手順

オダで確立した制作方法を、いけ・みち・館長・坂元・内貴・黒野へ展開するための共通仕様。
実在の出演者写真は、本人の了承を得た素材だけを使用する。

## 1. 制作方針

- 写真に写る本人の容姿を基準にし、本人らしさをどこまで保つかはキャラクターごとの承認済み仕様に従う。**いけは「役者の見たまま」を保ったゲームキャラクター化**を行う。
- 舞台での役柄と衣装を優先し、普段着の写真は顔立ちや体格の補助資料として扱う。
- オダと同じ、家族向けだが子どもに寄せすぎないアニメ調。輪郭線は手描き感を残し、過度に滑らかなAIイラスト感を避ける。
- 全身絵と会話絵は繊細な2Dアニメイラスト、歩行絵はHD-2Dフィールドになじむ2頭身ドット絵にする。
- ヘッドセットマイクなど、舞台上だけの機材は指定がない限り外す。
- 画像は生成時の解像度を維持し、リサイズや再圧縮をしない。ゲーム内サイズはCanvas側で調整する。

## 2. 制作前ヒアリング

キャラクターごとに、生成前に次を確定する。

1. 写真から受け継ぐ特徴と、本人らしさの再現度
2. 固定する舞台衣装、色、装具、名札、武器、小道具
3. 外すもの（ヘッドセット、現代的な私物など）
4. 年齢感、体格、姿勢、役柄の第一印象
5. 全身絵のポーズと視線
6. 基本表情と、その人物らしい怒り方・笑い方
7. 武器や小道具を歩行絵にも含めるか
8. 写真使用とゲーム内での扱いについての本人了承

## 3. 必要な参照画像

- 正面に近い顔写真1枚以上
- 斜め顔または自然な表情の写真1枚以上
- 全身または体格が分かる写真1枚以上
- 舞台衣装が分かる写真1枚以上
- 画風基準: `prototype/assets/chara/oda_full.png`
- 会話絵の構図基準: `prototype/assets/face/oda_neutral.png`
- 歩行シートの配置基準: `prototype/assets/sprites/oda_walk.png`
- 走行シートの配置基準: `prototype/assets/sprites/oda_run.png`

同じ写真を複数用途で使ってもよいが、役割をプロンプト内で明記する。

## 4. 納品する画像とファイル名

`<kind>` は `oda / ike / michi / kancho / sakamoto / naiki / kurono` のいずれか。

| 種類 | ファイル | 用途 |
|---|---|---|
| 全身ベース | `prototype/assets/chara/<kind>_full.png` | タイトル、戦闘、カットシーン |
| 通常表情 | `prototype/assets/face/<kind>_neutral.png` | 会話 |
| 真剣・困惑 | `prototype/assets/face/<kind>_serious.png` | 会話 |
| 怒り・強い反応 | `prototype/assets/face/<kind>_angry.png` | 会話 |
| 笑顔 | `prototype/assets/face/<kind>_happy.png` | 会話 |
| 驚き（必要な人物） | `prototype/assets/face/<kind>_surprised.png` | 会話 |
| 互換用通常顔 | `prototype/assets/face/<kind>.png` | 表情指定なし・フォールバック |
| 歩行12コマ | `prototype/assets/sprites/<kind>_walk.png` | フィールド |
| 走行12コマ | `prototype/assets/sprites/<kind>_run.png` | フィールド・追跡演出 |
| 戦闘用 | `prototype/assets/enemy/<kind>_battle.png` | 戦闘・イベント |

`<kind>.png` は `neutral` と同じ画像を使う。ゲームは表情画像がない場合、自動的にこのファイルへ戻る。

## 5. 共通画風

- 日本の2Dアニメーション用キャラクターデザインに近い手描き感
- やわらかな線、自然な布のしわ、抑えた彩度、明るい昼光
- 顔の輪郭はわずかに丸く、目は読みやすいが大きくしすぎない
- 肌や髪を均一なプラスチック質感にしない
- 過剰な逆光、被写界深度、粒子、発光、厚い油彩、写実写真調を避ける
- 既存の踊り子やオダと並んでも年齢層・作品トーンがずれないこと

## 6. 全身ベース絵プロンプト

```text
Use case: stylized-concept
Asset type: Japanese RPG character key art
Primary request: 添付写真に写る「<キャラ名>」を、承認済みの本人らしさを保ちつつ、
オダと統一したゲームキャラクターとして描く。
Input images: 人物写真=顔立ち・髪型・体格の参考、舞台写真=衣装と役柄の参考、
オダ全身絵=画風・線・彩色・年齢感の基準。
Subject: <髪型、輪郭、体格、衣装、小道具、外すもの>
Style/medium: 家族向けだが幼すぎない日本の2Dアニメ調。自然な手描き線と布の質感。
Composition/framing: 全身、正面やや斜め、頭から足先まで切らずに収める。
Expression/pose: <表情とポーズ>
Lighting/mood: やわらかな昼光、落ち着いた歴史ファンタジーRPG。
Scene/backdrop: 完全に均一な #ff00ff のクロマキー背景。
Constraints: キャラクター以外を描かない。影、床、文字、ロゴ、透かしなし。
Avoid: 写真調の描画、成人向けの重厚さ、幼児向けデフォルメ、AI的な過剰光沢、
余分な指、衣装の改変、指定していない武器やアクセサリー。
```

## 7. 会話用表情プロンプト

最初にニュートラルを作り、その画像を基準に残りの表情を作る。髪型、眼鏡、衣装、顔の比率、カメラ位置を変えない。いけは5表情を必須とする。

```text
Use case: stylized-concept
Asset type: square RPG dialogue portrait
Primary request: 「<キャラ名>」の会話ウィンドウ用バストアップ。
Input images: 人物写真=特徴の参考、承認済み全身絵=キャラクターデザインの固定基準、
オダ会話絵=構図と画風の基準。
Composition/framing: 正面目線。頭頂を切らず、肩から上が大きく入る正方形構図。
Expression: <neutral / serious / angry / happy / surprised の具体的な表情>
Style/medium: 全身絵と完全に同じ線・彩色・年齢感。
Scene/backdrop: 完全に均一な #ff00ff のクロマキー背景。
Constraints: 顔の同一性、髪型、衣装、カメラ位置を全表情で固定。手、小道具、文字、影なし。
Avoid: 表情ごとの別人化、顔の細すぎる輪郭、目の過剰な拡大、口や眼鏡の崩れ。
```

表情の基準:

- `neutral`: 口を閉じた自然な正面顔
- `serious`: 少し困りながらも真剣。眉をわずかに寄せる
- `angry`: 役柄に合った怒り・ツッコミ。顔を歪ませすぎない
- `happy`: 自然な笑顔。目を完全に閉じるかはキャラごとに決める
- `surprised`: 目と口を自然に開いた驚き。誇張しすぎず、その人物の顔立ちを保つ

## 8. 歩行・走行シートプロンプト

```text
Use case: stylized-concept
Asset type: HD-2D RPG walking sprite sheet
Primary request: 承認済みキャラクターを2頭身の歩行ドット絵にする。
Input images: 承認済み全身絵=デザイン固定、oda_walk.png=配置と縮尺の固定基準。
Composition: 3列×4行の12セル。
Rows: 1=正面、2=左、3=右、4=後ろ。
Columns: 1=直立、2=右足前、3=左足前。
Constraints: 全セルで頭身、中心、足元、衣装、色、輪郭を固定。
背景は完全に均一な #ff00ff。文字、罫線、セル番号、影なし。
Avoid: セル結合、コマ欠落、向き違い、フレームごとの顔や体格の変化、
歩行中の上下左右の位置ずれ。
```

走行シートは同じ3列×4行・同じ頭身と接地点で作り、直立コマの代わりに走りの通過姿勢、左右列に大きく異なる踏み込みを置く。歩行シートの単純な早回しにはせず、上体の前傾、腕振り、蹴り出しで走行を読ませる。

```text
Use case: stylized-concept
Asset type: HD-2D RPG running sprite sheet
Primary request: 承認済みキャラクターを2頭身の専用走行ドット絵にする。
Input images: 承認済み全身絵=デザイン固定、同人物のwalk=頭身・色・接地点の固定基準。
Composition: 3列×4行の12セル。
Rows: 1=正面、2=左、3=右、4=後ろ。
Columns: 走行サイクルの3姿勢。左右の踏み込みと腕振りを明確に変える。
Constraints: 全セルで頭身、中心、足元、衣装、色、輪郭を固定。
背景は完全に均一な #ff00ff。文字、罫線、セル番号、影なし。
Avoid: 歩行の流用、過度な前傾、空中静止、セルごとの縮尺変化、武器の追加。
```

### 戦闘用一枚絵

```text
Use case: stylized-concept
Asset type: transparent RPG battle character art
Primary request: 承認済みキャラクターの戦闘用全身一枚絵。
Input images: 承認済み全身絵=人物・衣装・配色の固定基準。
Composition/framing: 頭から足先まで切らず、足元を下寄せした読みやすい構え。
Expression/pose: 役柄に合う緊張感。武器はキャラクター仕様に明記された場合だけ描く。
Scene/backdrop: 完全に均一な #ff00ff のクロマキー背景。
Constraints: 全身絵と同じ人物、年齢感、体格、髪型、衣装。文字、床、影、ロゴなし。
Avoid: 指定していない刀・槍・兜、衣装の再設計、過度な流血、写真調。
```

## 9. 背景透過

組み込み前に、内蔵画像生成で作った均一なクロマキー背景をローカル処理する。

```bash
python "$HOME/.codex/skills/.system/imagegen/scripts/remove_chroma_key.py" \
  --input <生成画像> \
  --out <透過画像.png> \
  --key-color '#ff00ff' \
  --soft-matte \
  --transparent-threshold 55 \
  --opaque-threshold 150 \
  --despill \
  --force
```

確認項目:

- 四隅のalphaが0
- 顔、首、手、服の内側が透明になっていない
- 輪郭にマゼンタの縁が残っていない
- 目、眼鏡、髪の細部が欠けていない
- 元画像の解像度を維持している

## 10. 歩行・走行シート補正

生成された各12コマは、そのまま使わず中心と足元を補正する。

```bash
python scripts/repack_sprite_sheet.py <透過前シート.png> \
  prototype/assets/sprites/<kind>_walk.png

python scripts/repack_sprite_sheet.py <透過前シート.png> \
  prototype/assets/sprites/<kind>_run.png
```

ゲーム側もセルごとのalpha範囲を解析し、水平中心と足元を固定して描画する。補正後は上下左右、斜め、方向反転、壁押し、停止、歩行から走行への切替を実画面で確認する。

## 11. ゲームへの接続

- 顔画像はファイル名どおり置けば読み込まれる。
- セリフに `face: 'neutral' | 'serious' | 'angry' | 'happy' | 'surprised'` を付けると表情を固定できる。
- セリフエディターでも表情を選択できる。
- 表情画像がない場合は `<kind>.png`、さらに画像がなければ既存の図形ポートレートへ戻る。
- 主要人物の会話絵は、オダと同じ肩上クロップで表示される。
- 歩行シートは `<kind>_walk.png` を置けば自動反映される。
- 走行シートは `<kind>_run.png` を置く。方向入力中にBで通常速度の1.6倍になり、スタミナは消費しない。停止中のB短押しとXはメニューを開き、イベント・カットシーン中は走行しない。
- 戦闘絵は `assets/enemy/<kind>_battle.png` に置き、戦闘・イベントの該当描画へ接続する。
- 全身絵は用途ごとにタイトル・戦闘・カットシーンの描画コードへ接続する。

## 12. 実画面QA

- 会話枠内で顔が小さすぎず、頭頂と肩が切れない
- 読み込み時に別キャラや旧ダミーが一瞬出ない
- 全表情で顔、髪、眼鏡、衣装が同一人物として安定する
- 全身絵と会話絵で年齢感・体格・衣装が一致する
- 歩行12コマに横跳び、足元の上下、向き違いがない
- 走行12コマが歩行の早回しに見えず、1.6倍速でもカクつき、空中静止、足滑りがない
- B＋方向、B単独、X、イベント中の入力がそれぞれ仕様どおりに分岐する
- 背景色の縁、透明穴、余分な影、文字がない
- 512×448の実ゲーム画面で表情とシルエットが読み取れる

## 14. 現在の基準と確定仕様

- オダ: `oda_full` / 会話4表情 / `oda_walk` / 専用4方向12コマの `oda_run` 導入済み。
- みち: 深緑〜黒系の陣羽織、豪快な荒武者。大身槍「人間無骨」を各画像に含める範囲の最終ヒアリング待ち。

### いけ（kind: `ike`）

- 写真使用・ゲーム内使用の了承: ユーザー確認済み素材を使用する。
- 参照写真: `DSC_9351.JPG`、`DSC_9358.JPG`、`DSC_9373.JPG`、`DSC_9409.JPG`（リポジトリ外の提供素材）。
- 本人らしさの再現度: **役者の見たまま**。顔立ち、年齢感、体格、髪型を写真の人物から変えず、オダと統一したアニメ調へ変換する。若い男性武者や汎用武将へ置き換えない。
- 固定衣装: 舞台写真の具足をそのまま基準にする。黒を基調とした袖・胴、赤・緑・白の威し、胸元の金襴、白い襟元、白い腰帯、黒い袴・脚絆。
- 固定特徴: 黒髪を後ろで結び、白い髪飾りを付ける。頬の舞台メイクの線を残す。
- 外すもの: ヘッドセットマイク。刀は差さず、手にも持たせない。
- 会話5表情: `neutral`、大きく笑う `happy`、役柄らしい `angry`、張り詰めた `serious`、自然に目と口を開く `surprised`。
- 必須納品: `ike_full.png`、`ike.png`（neutral互換）、上記5表情、`ike_walk.png`、`ike_run.png`、`ike_battle.png`。
- 顔の基準は正面の黒衣プロフィール写真を最優先とし、白衣写真は笑顔と親しみやすさの補助に使う。年齢を若返らせず、輪郭・目・鼻・口の本人性を保つ。
- 「華」は澄んだ目、健康的な明るさ、控えめな頬・唇の色に限定する。通常顔は微笑ませず、静かな覚悟と少しの勇ましさを眉・目線・口元で示す。
- 甲冑は舞台衣装の配色と構造を維持しつつ、威糸の過剰な反復、粒状ノイズ、プラスチック状の光沢を避け、板・布・金襴の素材差が読める手描き表現にする。
- 歩行・走行・戦闘の全画像で、具足の配色、白い髪飾り、頬の線、白い腰帯を省略しない。刀とヘッドセットは全画像で描かない。

## 登場人物（p2）

| 役 | 説明 |
|---|---|
| オダ | 社会人2年目。ひょんなことから古戦場記念館に勤務。それほど歴史がすきなわけでもない |
| いけ | 池田輝政（てるまさ）。池田恒興の次男。小牧長久手の戦いで生き残り、後に池田家の家主となる。家康から付与された大包平（おおかねひら）は刀剣乱舞で一躍有名。**劇中、終幕まで刀を持っていない**（重要な前提） |
| みち | 林通具（みちとも）。森長可の軍で戦った武将だが詳細は不明。小牧長久手の戦いにて命を落とす |
| 館長 | 記念館の館長。ラーメン好き |
| 踊り子 | 能のような舞を舞う謎の存在。いけ・みちには見えない |

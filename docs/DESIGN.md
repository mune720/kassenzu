## 0. 決定事項（ヒアリング結果）

| 項目 | 決定 |
|---|---|
| 規模 | クリアまで約2時間（本編90分＋おまけ30分） |
| 本編 | 原作脚本に忠実（現状の圧縮部分をフル復元）。原作にないフィールドはおまけ扱い、行かなくてもクリア可 |
| マップ | 屋外＝カメラスクロール型、屋内（記念館・イオン・図書館等）＝固定画面 |
| 戦闘 | パーティ戦闘に拡張（最大3人）。いけ・みちの仲間加入イベントあり |
| ミニゲーム | 謎解き・パズル／アクション／リズム／収集・探索 すべて採用 |
| 難易度 | イージー（市民全般向け）／ハード（玄人向け・本格派）の2モード |
| 実在施設 | すべて実名で登場（※イオン等民間施設の掲載許諾の確認はユーザー側で実施） |
| 素材 | まず仮素材（Canvas描画・生成画像）で全部作る → ASSETS.md の差し替え一覧で後から差し替え。現地写真・立ち絵・BGM/SEはユーザーから提供可能 |

### 原作再現の大前提（検証で確定）

- **いけは終幕まで刀を持たない**。刀を向けるのは常にみち。いけの戦闘参加は素手（型稽古・かばう）に限る。刀技はポストゲームで大包平入手後にのみ解禁（S21伏線の回収）。
- 早口言葉「いずみのかみかねさだ」で**噛むのはオダ**（プレイヤー）。いけは正しく言える。

- タイトルの「史跡めぐり」は**図鑑的モード**として存続: 旧形式のリスト選択で史跡イベント（学び＋クイズ＋戦闘）を単体再生。本編未クリアでもアクセス可。

## 4. システム拡張

### 4.1 カメラスクロール

- **方式: `ctx.translate(-camX, -camY)` でワールド座標のまま描画**し、可視タイル範囲 `[camX/TILE .. (camX+W)/TILE]` のみループする。drawTile は無改修で済む（drawTile は描画座標から tc/tr を逆算しているため、画面座標を渡す方式だと tileHash 由来の草・石・花がスクロール中にちらつく。translate 方式ならワールド座標が保たれ模様が安定する）。
- **描画を2パスに分離**:
  - ワールドパス（translate 内）: タイル・アクター・篝火グロー・フィールドパーティクル
  - スクリーンパス（translate 外）: フォグバンド・全画面ティント・ビネット・Dialog・HUD
- **パーティクルはワールド座標系に統一**し、発生位置はカメラ可視範囲基準で生成（現行は画面座標 rnd(20, W-20) 固定なので要修正）。
- カメラはプレイヤー中心・マップ端でクランプ。屋内マップ（16×14以下）はカメラ固定＝現行挙動。
- 性能の逃げ道: 重い場合はゾーン単位のオフスクリーンキャッシュ＋アニメタイル（'.', '~', 'P'）のみ毎フレーム再描画。

### 4.2 マップ接続（ゲートウェイ）

マップ定義を以下に一般化する（現行の SOLID 固定辞書・parseMap のハードコード・drawTile の museum/屋外2系統では新マップ追加時にクラッシュ/誤描画するため）:

```js
MAPS = {
  zoneA: {
    rows: [...], kind: 'outdoor',
    tileset: 'outdoor',            // 描画スタイル: outdoor / museum / mall / library / office / shop / hall
    solid: new Set([...]),          // 通行不可文字（マップごとに定義）
    encounter: { rate: 0.07, table: [...] } | null,
    npcs: { 'i': 'ike', 'm': 'michi', ... },   // 文字→NPC種のマップ別テーブル
    acts: { 'B': 'byobu', ... },                // 文字→アクションIDのマップ別テーブル
    edges: { west: { map: 'zoneC', spawn: { col: 35, row: 14 } } },
    doors: { '10,5': { to: 'museum', spawn: {...} } },
  }, ...
}
```

- 屋外ゾーン端→隣ゾーン: フェードなしの即時切替。**スポーン指定はピクセル座標 {x, y} を直接引き継げるようにする**（タイル中心スナップだと切替時に数pxワープして見える）。
- 施設入口→屋内: 現行 startTransition のフェードを流用。
- `runAction` の storyStage 分岐チェーンは章再編で全面書き換えになるため、**マップ別イベントテーブル化を P1 スコープに含める**。
- spawnFieldParts・大気オーバーレイの mapKey 直値分岐も tileset ベースに再編。

### 4.3 パーティ戦闘（最大3人）

- `Hero` → `party: [oda, ike?, michi?]`。各メンバー: hp/maxhp/atk/技リスト/立ち絵kind。
- **行動主体を actor パラメータ化し、戦闘メッセージをテンプレート化**（現行は 'オダ' 固定文言が enemyTurn/playerTurn/winSequence/みやぶるに埋め込まれている）。
- コマンド: 「たたかう／わざ／どうぐ」共通＋**「みやぶる」はオダ専用**（＝ガイドトークとして強化。他メンバーの技リストと排他）。
- 技: いけ「体当たり」「かばう」（**本編は素手・刀なし**。刀技「一閃」はポストゲームで大包平入手後に解禁）、みち「人間無骨」（槍・高威力）。
- **経験値・レベルはオダに集約**（いけ・みちは加入時固定ステータス）。装備もオダ専用のまま。メニューのステータスタブに加入中メンバーの固定ステータスを併記。
- **全滅条件＝オダのHP0**（仲間が倒れても戦闘継続、戦闘後に復帰）。
- forcelose/spar（二章の腕試し・五章のみち対峙）はイベント戦: 所定ターン経過またはHP条件でスクリプト進行。五章後は1vs1状態に戻す復帰処理を用意。
- **UIレイアウト**: 味方枠は左下 x=22、y=240 から28px間隔で縦積み（名前＋HPバー、バー幅170→150に縮小）。敵名表示 y=208 との重なりに注意。コマンド窓（x=316, y=286）・テキストボックス（y≈325）は現行位置を維持。

### 4.4 難易度（イージー／ハード）

- タイトルで選択、セーブに保存。メニューからハード→イージーのみ変更可。
- イージー: 敵HP/攻撃 −30%、クイズ3択＋ヒントあり、ミニゲーム失敗でも進行（リトライ任意）、エンカウント率低。
- ハード: 敵HP/攻撃 +40%、クイズ4択ノーヒント＋高度な史実問題、ミニゲーム成功必須（リトライ可）、ハード専用ボス（ポストゲーム）、収集コンプが図鑑に反映。
- **クイズデータは二層スキーマに拡張**: `{ q, easy: {choices, answer, hint}, hard: {choices, answer} }`。editor.html のセクション表示対応を P5 に含める。

### 4.5 進行管理・セーブ

- `storyStage` を章ベース（ch0〜ch7＋post）に再編。
- **セーブキーを v2 に更新**（`kassenzu_save_v2`）し、v1 からの読み替え関数を用意:

### 4.6 セリフデータ

- dialogue.js を章別セクションで大幅拡張（原作全文ベース。1ウィンドウ3行以内に分割）。
- editor.html 互換維持。キー命名: `ch2_ike_meet_1` など章_場面_連番。
- **マージ安全規約（重要）**: localStorage マージはトップレベルキー単位の浅い上書きのため、**新規の戦闘メッセージ・クイズ等はネストせず必ずトップレベルキーとして追加する**（例: `battle_mononoke_party`。既存 `battle`/`sites` 配下への新サブキー追加は禁止——旧保存データが優先されて undefined フリーズが再発する。コミット 323830b と同型のバグ防止）。

### 4.7 アイテム・通貨（新設）

- ITEMS に `type: 'consumable'` を追加（例: おにぎり=HP回復、長久手茶=HP大回復、兵糧丸=戦闘中攻撃UP）。

## 7. 仲間加入イベント

- **みち加入（四章）**: 戦トーク後、疑念が呼んだ「はぐれもののけ」襲来→「ちっとは戦えるようになっとけ！」で共闘（パーティ戦闘チュートリアル）。

- **原作整合**: 本編ではみちは六章で戦線へ、いけは森へ去る（原作どおり離脱）。
- **ポストゲーム**: クリア後「もしもの長久手」として勝入塚に祈ると2人が期間限定で再集結→自由編成でハード専用ボス・収集コンプに挑める（おまけ扱い・原作の外伝と明記）。いけは大包平を携えて再登場し、刀技「一閃」解禁（S21「一国に替え難い名刀」の回収）。

## 10. リスクと対応

- **セリフ量の増大**: dialogue.js が数千行規模になる → 章別に整理しエディターのセクション表示を維持。
- **スクロール性能**: 可視タイルのみ描画で対応（描画枚数は現行と同等）。重い場合はゾーン単位オフスクリーンキャッシュ＋アニメタイル（'.', '~', 'P'）のみ毎フレーム再描画。
- **dialogue マージ事故**: 新キーは必ずトップレベルに追加（4.6の規約）。エディター保存データとの衝突を防ぐ。
- **原作の権利**: 公演脚本の利用は文化の家事業の一環として許諾済み前提（ユーザー側確認）。イオン実名も同様。
- **既存セーブ互換**: v1→v2 変換レイヤーを P1 で用意（4.5の変換表）。

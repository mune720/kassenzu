# HD-2D グラフィック素材 生成プロンプト集（第1弾: フィールド）

ChatGPT の画像生成に、そのまま貼り付けて使うプロンプト集。
生成した画像は `prototype/assets/` に入れて報告してもらえれば、リネーム・配置・登録はこちらで行う（`CLAUDE.md` のアセット管理ルールどおり）。**ゲーム側は下記ファイル名を自動で読む**ため、先に自分で置く場合は「保存先」のファイル名にすること。

## 使い方

1. 各プロンプトの先頭に、下の【共通スタイル指定】を毎回コピーして付ける（画風ブレ防止）
2. 生成サイズはプロンプト内の指定どおり（1024×1024 / 1536×1024 / 1024×1536）
3. 気に入らなければ「同じ構図のまま、◯◯だけ変えて」と追加指示でリテイク
4. できた画像はリサイズ・圧縮せずそのまま `prototype/assets/` へ（解像度を下げないルール）

## 【共通スタイル指定】（毎回プロンプトの先頭に付ける）

> 高精細な日本製レトロRPG風のドット絵（ピクセルアート）ゲーム素材。オクトパストラベラーのようなHD-2D調の繊細なドット表現。落ち着いた自然な彩度、やわらかい昼光。強い影・夜の色味・光のエフェクトは描き込まない（ゲーム側で照明を合成するため）。写実・3DCG・水彩イラスト調は禁止。

## D. 【試作】キャラクター歩行スプライト（まず1枚だけ試す）

生成AIはコマ割りの整列が苦手なため、**まずオダ1枚を生成して使えるか判定**する。ズレが大きければキャラはコード描画の強化に切り替える（第2弾で対応）。

### D-1. オダ 歩行シート → `assets/sprites/oda_walk.png`（1024×1024）
> RPGの歩行スプライトシート。1024×1024・背景透過。同じキャラクターを3列×4行の12マスに等間隔で整列させる。全マスでキャラの大きさ・足元の位置を完全にそろえること。
> 行の内訳: 1行目=正面（下向き）、2行目=左向き、3行目=右向き、4行目=後ろ姿。
> 列の内訳: 左=直立、中央=右足を前に歩く、右=左足を前に歩く。
> キャラクター: 20代の歴史記念館スタッフの女性「オダ」。黒のショートボブ、白いシャツに紺のエプロン、胸に名札。2頭身のちびキャラのドット絵。

# 第2弾: キャラクタービジュアル（実際の写真から起こす）

対象は主要6人（オダ・いけ・みち・館長・踊り子・坂元）。**各生成に写真を添付する形式**。
出演者などの写真を使う場合は、本人の了承を得たうえで使うこと。

## 各キャラに作るもの（3種類）と保存先

| 種類 | 用途 | 保存先（この名前なら自動で反映） |
|---|---|---|
| ベースビジュアル（全身一枚絵） | タイトルロール・戦闘・カットシーン | `assets/chara/<キャラ>_full.png`（例: oda_full.png） |
| 顔ウィンドウ（バストアップ） | 会話画面の顔（**入れるだけで反映**） | `assets/face/<キャラ>.png`（例: oda.png） |
| 歩行ちびドット（3列×4行） | フィールドの歩行キャラ（**入れるだけで反映**） | `assets/sprites/<キャラ>_walk.png` |

キャラ名: oda / ike / michi / kancho / odoriko / sakamoto
※踊り子のベースビジュアルは既存（`assets/enemy/odoriko_battle.png`）を使うため生成不要。
※踊り子は歩行ドットを入れると、舞いの演出シーン以外はフィールドでちびドット表示に切り替わる（対応済み）。

## タイプ1: ベースビジュアル（全身一枚絵・1024×1536・透過）

添付2枚: ①人物の写真 ②画風の参考として踊り子の絵（`prototype/assets/enemy/odoriko_battle.png`）

> 添付1枚目は実在の人物の写真、添付2枚目はこのゲームの画風見本（踊り子のイラスト）です。写真の人物の顔立ち・髪型・体格・雰囲気の特徴をとらえつつ、そっくりの似顔絵ではなくゲームキャラクターとしてほどよくデフォルメして描き起こしてください。画風・質感・光の当て方・線の柔らかさは添付2枚目のイラストに完全に合わせてください（繊細な和風ファンタジーイラスト調）。全身立ち姿、正面やや斜め、頭から足まで収める。背景は完全に透過。1024×1536。
> 衣装とポーズ: 【キャラ別指定を貼る】
